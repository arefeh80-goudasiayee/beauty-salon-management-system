# سیستم مدیریت سالن آرایشی

این مخزن شامل مستندات مرحله‌ای پروژه «سیستم مدیریت سالن آرایشی» برای درس مهندسی نرم‌افزار است. موضوع پروژه، طراحی یک سامانه برای مدیریت مشتریان، خدمات، کارکنان، نوبت‌دهی و پرداخت‌های یک سالن آرایشی است.

## ساختار پروژه

| جلسه | موضوع | مستندات |
|---|---|---|
| ۱ | توسعه چابک و Scrum | پنج داستان کاربر و Product Backlog اولیه |
| ۲ | مهندسی نیازمندی‌ها | ذی‌نفعان، نیازمندی‌های عملکردی و غیرعملکردی |
| ۳ | مدل‌سازی نیازمندی‌ها و UML | نمودار Use Case و Activity برای رزرو نوبت |
| ۴ | اصول طراحی نرم‌افزار | ماژول‌بندی، انسجام (Cohesion) و وابستگی (Coupling) |
| ۵ | معماری نرم‌افزار | معماری لایه‌ای و رابط کامپوننت‌ها |

## محدوده سامانه

سامانه برای یک سالن آرایشی در نظر گرفته شده و هدف آن ساده‌تر کردن کارهای روزمره سالن است. مشتری می‌تواند خدمات و زمان‌های خالی را مشاهده و درخواست نوبت ثبت کند. کارکنان و مسئول پذیرش نوبت‌ها را مدیریت می‌کنند و مدیر سالن به اطلاعات خدمات، کارکنان و گزارش‌ها دسترسی دارد.

## نقش‌های اصلی

- مشتری
- مسئول پذیرش
- آرایشگر یا ارائه‌دهنده خدمت
- مدیر سالن
- مسئول مالی (در صورت تفکیک این مسئولیت در سالن)

## فرض‌های اولیه

- نسخه اولیه سامانه برای یک سالن طراحی می‌شود.
- هر نوبت به یک مشتری، یک خدمت، یک ارائه‌دهنده خدمت و یک بازه زمانی مربوط است.
- ثبت نهایی نوبت فقط در صورت آزاد بودن بازه زمانی انجام می‌شود.
- پرداخت می‌تواند هنگام مراجعه یا پس از انجام خدمت ثبت شود.
- ارسال پیامک یادآوری در نسخه اولیه به‌عنوان قابلیت قابل توسعه در نظر گرفته شده است.
